    关于 TransitTruth
    
                
    
                
    
                    
    这是什么？
    
                    
    TransitTruth 是一个开源的 AI API 中转站审计工具，帮助用户验证中转站是否存在以下问题：
    
                    
      
                        
    • Token 计数造假：实际用 1000 token，收 1500 token 的钱
      • 
                        
    • 模型降级：付了 GPT-4o 的钱，实际返回 GPT-3.5
      • 
                        
    • 缓存响应：不实际调用 API，返回缓存结果
      • 
                        
    • 协议不合规：响应格式不符合 OpenAI API 规范
      • 
                    
    

                    
    检测原理
    
                    
      
                        
    • Tokenizer 指纹：不同模型家族用不同 tokenizer，发送精心构造的字符串，对比 token 计数
      • 
                        
    • 行为指纹：不同模型在随机数生成、颜色命名等任务上有不同的分布偏好
      • 
                        
    • 能力测试：简单推理/代码题区分模型等级
      • 
                        
    • Token 对比：与官方 API 或本地 tiktoken 计算结果对比
      • 
                    
    

                    
    全民共建
    
                    
    排行榜数据由社区用户贡献，完全公开可复现。完成审计后可选择贡献结果，帮助更多用户。
    

                    
    免责声明
    
                    
    重要提示：
    
                    
      
                        
    • 本工具仅供用户验证自己使用的服务，审计结果基于有限样本，不构成对任何服务的最终评价。
      • 
                        
    • Token 差异率包含 chat template 开销，不等同于造假。如需确认造假，请与官方 API 精确对比。
      • 
                        
    • 模型指纹检测为概率性判断，置信度低于 80% 时不构成模型降级的证据。
      • 
                        
    • 排行榜数据由社区用户贡献，未经独立验证，仅供参考。
      • 
                        
    • API Key 仅用于本次审计，不会存储到服务器。
      • 
                        
    • 如对审计结果有异议，可在 GitHub 提交 Issue 并附上反驳证据。
      • 
                    
    

                    
    开源
    
                    
    本项目完全开源，欢迎贡献代码和探针测试集。
