🚀 本地一键开测：打开网页就能验真

5 秒看懂：
  1. 本机安装后运行 transit-truth serve，浏览器打开 http://127.0.0.1:8766。
  2. 填中转站 base_url 与声称模型（如 gpt-4o-mini），可选填 Key（仅本地内存，不落盘/不进日志/不进分享报告）。
  3. 本地服务端发探针电池 → tokenizer 计数（弱信号）+ 行为分布（主判据）→ 三态 fail-closed 结论。
pip install .
transit-truth serve  # 默认 http://127.0.0.1:8766，加 --open 自动开浏览器

工作原理：服务端向目标发有界探针，对比本地参考分布；行为分布（卡方 + KS + 贝叶斯后验 / LR / 95%CI）才是主判据， tokenizer 计数只是可被公开模仿的弱信号；三态 pass（行为支持） / suspicious（显著不符） / insufficient_evidence（证据不足，不硬判）。

为什么这个静态网页不能直接测：浏览器直连第三方中转站受 CORS 限制，且不应把 Key 交给目标域。 本 GitHub Pages 页面只是门面 / 引导 / 离线演示；实时后端必须跑在能执行 Python 的本机、VPS 或 Docker 容器里 （见 docs/serve.md；Cloudflare Workers/Pages 无法运行 Python 引擎）。
