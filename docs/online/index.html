Key 只存在本页内存，直接发往你自己填写的端点；不存 localStorage、不进 URL、不写日志。

    能力边界 · Honest limits（请先读）
    
    
      
      
    • 概率性辅助证据，不是密码学证明。本页不签发"正品证书"；
        pass 在浏览器版不会被签发，主判定（行为分布卡方/KS/贝叶斯后验）需要本地 CLI。
        Probabilistic auxiliary evidence, NOT cryptographic proof. The browser build never emits pass; primary statistics require the local CLI.
      • 
      
    • 开源指纹覆盖有限。仓内真实行为基线仅 gpt-4o / gpt-4o-mini（各 n=50）；
        开放 tokenizer 指纹仅 qwen2.5-0.5b 与 deepseek-r1-distill-qwen-1.5b（均无行为分布）。
        浏览器也无法运行 tiktoken BPE 计数，tokenizer 探针在本页被跳过。
        Limited open coverage; tokenizer counting (tiktoken) cannot run in-browser and is skipped here.
      • 
      
    • temperature=0 回放可能被误读。单次/少数样本的"答对"不代表模型真身，
        "答错"也可能是端点限流、拒答或措辞差异。
        Few-shot temperature=0 replay is weak signal; a correct answer is not certification.
      • 
      
    • 不评判服务端隐私 / 合规 / 价格。本页只检查协议可达与表面能力，
        不判断该服务是否合法、是否留存你的对话。
        No privacy, compliance or pricing judgment; this page does not evaluate legality.
      • 
      
    • 无服务端中转。本 Pages 是纯静态页面，没有代理后端；你的 Key 不经过本项目任何服务器。
        No server relay: static Pages only; your key never touches this project's servers.
