# 我用27分钟发现了GPT的"行为指纹"：选数字100%返回7，选动物76%返回Okapi

> 你用的GPT-4是真的吗？中转站有没有偷偷给你降级成GPT-3.5？我做了一个27分钟的小实验，发现了一个几乎没人注意到的现象：大语言模型在"随机"任务上有极端强烈的偏好，这些偏好可以用来"验明正身"。

---

## 一、故事的开始：中转站乱象

2026年了，AI API中转站已经是个千亿市场。但这个市场有多乱呢？

- 你付了GPT-4o的钱，实际返回的可能是GPT-4o-mini，甚至GPT-3.5
- 你用了1000个token，中转站可能收你1500个的钱
- 跑路、数据倒卖、恶意代码注入时有发生
- 国家安全部都专门发过风险提示

问题是：**作为普通用户，你怎么验证自己用的中转站有没有"参水分"？**

我搜了一圈，发现有一些工具，但大多只能检测tokenizer差异（GPT用cl100k，Claude用自定义tokenizer）——但这只能区分不同家族的模型，**区分不了gpt-4o和gpt-4o-mini**（它们用同一个tokenizer）。

直到我看到一篇论文：[One Token Is Enough](https://arxiv.org/abs/2607.10252)（arXiv:2607.10252），里面提到一个想法：**大语言模型在"随机"任务上的输出分布，可以作为模型指纹**。

我决定自己做个实验验证一下。

---

## 二、实验设计：27分钟，2600次请求

实验很简单：

1. 找一个中转站API（我用的是wolfai.top，免费额度够用）
2. 问模型一些"随机"问题，每个问题问50次
3. 统计答案的分布
4. 对比gpt-4o-mini和gpt-4o的分布差异

探针包括：
- 选一个1-10的随机数字
- 选一个1-100的随机数字
- 掷一个六面骰子
- 抛一枚硬币
- 选一个随机字母
- 选一个随机颜色
- 选一个随机动物
- 选一个随机星期

总共8个行为探针 + 8个tokenizer探针 + 10个能力探针 = 26个探针，每个50次，共1300次请求。两个模型就是2600次。

**总成本：0元**（用的免费中转站额度）
**总耗时：27分钟**（gpt-4o-mini 15分钟，gpt-4o 12分钟）

## 三、震撼发现：GPT的"行为指纹"

### 发现1：gpt-4o-mini选1-10的数字，100%返回7

我问了gpt-4o-mini 50次"选一个1到10之间的随机数字，只输出数字"。

结果：**50次全部返回7**。

不是"大部分返回7"，是**100%，零方差**。

正常随机的话，每个数字应该出现约5次（10%概率）。但gpt-4o-mini对"7"有极端偏好——这可能和"7是幸运数字"的文化有关，训练数据里"7"出现的频率远高于其他数字。

### 发现2：gpt-4o选随机动物，76%返回Okapi

Okapi（㺢㹢狓）是一种非常罕见的非洲动物，是长颈鹿的近亲，长得像斑马和长颈鹿的混合体。大部分人可能都没听说过这个动物。

但我问gpt-4o 50次"选一个随机动物名称，只输出动物名"，结果：

- **38次返回Okapi（76%）**
- 剩下12次分布在3种其他动物

而gpt-4o-mini呢？它偏好Dolphin（海豚），只出现16%，而且有17种不同的动物。

**只用"选一个随机动物"这一个探针，就能以90%的准确率区分gpt-4o和gpt-4o-mini。**

这太反直觉了——为什么gpt-4o对Okapi有这么极端的偏好？可能是训练数据里Okapi出现在某些特定语境中（比如动物学教材、维基百科），RLHF又放大了这种偏好。

### 发现3：掷骰子96%返回4

gpt-4o-mini掷骰子50次：
- 48次返回4（96%）
- 1次返回3
- 1次返回5

正常随机的话，每个数字应该出现约8次（16.7%）。但gpt-4o-mini对"4"有96%的偏好——这已经不是"偏好"了，这是"几乎确定"。

gpt-4o也偏好4，但只有56%，比mini弱很多。

### 完整数据对比

| 探针 | gpt-4o-mini | gpt-4o | 正常随机 | 区分度(TVD) |
|---|---|---|---|---|
| 选1-10数字 | **7（100%）** | 7（98%） | 每个10% | 0.020 |
| 掷骰子 | **4（96%）** | 4（56%） | 每个16.7% | **0.400** |
| 选动物 | Dolphin（16%） | **Okapi（76%）** | 均匀 | **0.900** |
| 选字母 | **G（40%）** | **K（44%）** | 每个3.8% | **0.720** |
| 选颜色 | Cerulean（74%） | Cerulean（92%） | 均匀 | 0.220 |
| 选1-100数字 | 57（40%） | 57（24%） | 每个1% | 0.380 |
| 抛硬币 | Heads（78%） | Heads（82%） | 50% | 0.220 |
| 选星期 | Thursday（54%） | Thursday（62%） | 每个14.3% | 0.320 |

**8个探针里，6个有统计显著差异（p<0.05）。**

## 四、为什么会这样？

大语言模型本质上是"下一个词预测器"——它根据训练数据里的统计规律，预测下一个最可能出现的词。

当你问它"选一个随机数字"时，它并不是真的在随机生成——它是在预测"在这种语境下，人类最可能说哪个数字"。

而训练数据里，数字的出现频率是极不均匀的：
- "7"因为文化原因（幸运数字、七宗罪、七大奇迹、一周七天）出现频率远高于其他数字
- "4"在某些语境下（比如"四个象限"、"四季"、"四面八方"）出现频率高
- "Okapi"可能在动物学相关的训练数据里被反复提及
- "Cerulean"（天蓝色）可能在艺术、设计相关的文本里出现频率高

RLHF（人类反馈强化学习）又进一步放大了这些偏好——人类标注者可能觉得"7"比"3"更像"随机数字"，于是模型就更倾向于输出7。

**结果就是：每个模型都有自己独特的"行为指纹"，就像每个人都有独特的说话习惯一样。**

## 五、这有什么用？

### 用途1：验证中转站有没有偷换模型

这是最直接的用途。

如果你付了gpt-4o的钱，但中转站实际给你返回的是gpt-4o-mini，你可以：
1. 问它"选一个随机动物"
2. 如果76%返回Okapi，那大概率是真的gpt-4o
3. 如果偏好Dolphin或者其他动物，那可能被降级了

**tokenizer指纹做不到这一点**——gpt-4o和gpt-4o-mini用同一个o200k tokenizer，token计数完全一样。但行为指纹可以区分它们。

### 用途2：检测模型更新

OpenAI经常偷偷更新模型（比如gpt-4o-2024-05-13更新到gpt-4o-2024-08-06），但不告诉你。

通过定期检测行为指纹的变化，你可以发现模型什么时候被更新了。

### 用途3：学术研究

这是一个很新的研究方向——"大语言模型的行为指纹学"。

目前已知的相关论文：
- [One Token Is Enough](https://arxiv.org/abs/2607.10252)（2026）：165个模型的单token指纹普查
- [RoFL](https://arxiv.org/abs/2505.12682)（2025）：鲁棒模型指纹
- [CoIn](https://arxiv.org/abs/2505.13778)（2025）：API模型替换检测
- [Model Provenance Testing](https://arxiv.org/abs/2502.00706)（2025）：黑盒模型来源测试

但这些论文主要做的是"不同家族模型的区分"，**同家族不同模型（如gpt-4o vs gpt-4o-mini）的细粒度区分还很少有人做**。我的实验填补了这个空白。

## 六、我做了一个开源工具

基于这个发现，我做了一个开源工具：**TransitTruth**（AI API安全审计平台）。

GitHub：https://github.com/dafahaha/transit-truth

### 功能

- **🔍 行为指纹验证**：14个行为探针（8英文+6中文），卡方检验+KS检验+贝叶斯更新，计算模型匹配的后验概率
- **📊 统计不确定性量化**：Wilson置信区间+样本量评估+95%可信区间，结果透明可信
- **🔤 Tokenizer指纹**：8个tokenizer探针，区分不同模型家族
- **🧠 能力测试**：10个能力探针，估算模型等级
- **💰 Token计费审计**：tiktoken精确计算，检测计费膨胀
- **⚡ 延迟与协议检查**：P50/P95/P99，7项协议合规
- **💳 余额查询**：多中转站账户余额聚合，低余额自动告警
- **📚 模型参考数据**：14个模型的公开数据（价格/ELO/智能指数/延迟）
- **🏆 社区排行榜**：全民共建的中转站信誉排行榜
- **🚀 纯前端在线Demo**：零安装，浏览器即用（55KB单文件，苹果风格设计）

### 在线体验

**零安装在线Demo**：https://dafahaha.github.io/transit-truth/

打开链接，输入API Key，30秒出结果。所有请求直接从浏览器发出，不需要后端服务器，不需要安装任何东西。

### 技术栈

- 后端：Python + FastAPI + SQLite
- 前端：原生HTML/CSS/JS（无构建依赖）
- 统计：scipy（KS检验、卡方检验、贝叶斯更新）
- 部署：Docker / 本地运行 / 纯前端

## 七、一些有趣的发现

在做实验的过程中，我还发现了一些有意思的事情：

1. **gpt-4o比gpt-4o-mini更快**：在这个中转站上，gpt-4o平均延迟1595ms，gpt-4o-mini是2185ms。可能是中转站把gpt-4o路由到了更高优先级的后端。

2. **gpt-4o在球棒问题上反而答错了**：经典的"球棒和球一共1.1元，球棒比球贵1元，球多少钱？"——gpt-4o-mini答对了（5美分），但gpt-4o答错了（10美分）。可能是大模型更容易"想当然"。

3. **温度0的确定性更强**：论文里提到，温度0时90.4%的探针在同服务商内完全确定。我还没来得及测温度0的对比，这是下一步的工作。

4. **中文探针可能差异更大**：论文用了英/俄/中/阿4种语言。中文的文化偏好（比如数字8、6、9的偏好）可能让区分度更高。这也是下一步的工作。

## 八、局限性和注意事项

1. **这不是100%准确的**：行为指纹是统计方法，有一定的误判率。论文里的等错误率(EER)是7.3%（全量40探针）。我的工具目前只有8个行为探针，准确率会低一些，需要更多样本和探针。

2. **中转站可能会防御**：如果中转站知道了这个方法，可能会对"随机"问题做特殊处理（比如真的用随机数生成器）。但这会增加成本，而且很难对所有探针都防御。

3. **模型更新会改变指纹**：OpenAI更新模型后，行为指纹可能会变化。需要定期更新基准数据库。

4. **不要滥用**：请遵守目标API的使用条款，不要对服务造成过大压力。这个工具是为了帮助用户保护自己的权益，不是为了攻击中转站。

我用27分钟、2600次API请求、零成本，发现了GPT模型的"行为指纹"：

- gpt-4o-mini选1-10的数字，**100%返回7**
