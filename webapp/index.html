🔍 TransitTruth · 本地中转站验真

打开网页就能测：声称的模型是不是货真价实。概率性辅助证据，不是密码学证明。

5 秒看懂

  1. 填入中转站 base_url 和你声称的模型名（如 gpt-4o-mini）。
  2. 可选填 API Key（仅本浏览器会话内存使用，不落盘 / 不上传 / 不进日志 / 不进分享报告）。
  3. 点「开始核验」，本地服务端发探针 → tokenizer 计数 + 行为分布 → 三态 fail-closed 结论。
浏览器无法直连中转端点（受 CORS 限制），真实测试必须运行本地/自托管 transit-truth serve；本页由本地服务同源托管，后端在服务端发探针。 静态 GitHub Pages 只能做门面/引导，不能在线实测。
高级：采样与超时（一般不用改）
结论三态：pass（行为证据支持） · suspicious（与参考显著不符） · insufficient_evidence（证据不足，不硬判）。

工作原理

本地服务端向目标发有界探针电池（5 个 tokenizer 计数探针 + 4 个行为探针×重复）， 对比本地参考分布：tokenizer 计数是弱信号（不同家族可高度趋同）， 行为分布才是主判据（卡方 + KS + 贝叶斯更新，给后验/LR/95%CI）。 公开基线在 temperature=0 下可被确定性回放，报告显式标注 deterministic_replay_risk；官方密码学 attestation 才是终局。
